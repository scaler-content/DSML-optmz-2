The geometric picture of differentiation

Take two points on a curve, A at (x₁, f(x₁)) and B at (x₂, f(x₂)). A line through both points is called a secant, and its slope is the familiar rise-over-run:

slope = ( f(x₂) − f(x₁) ) / ( x₂ − x₁ )

Now fix point A and slide point B closer and closer to it. The gap between the point and the new one shrinks to a tiny amount we call Δx, so the second point becomes (x + Δx, f(x + Δx)). A line that touches the curve at only one point — the point the secant collapses onto — is called a tangent.

The derivative of f(x) at x = x₁ is defined as the slope of the tangent line at that point — the limit of the secant's slope as Δx shrinks to 0.
f′(x₁) = limΔx→0 [ f(x₁ + Δx) − f(x₁) ] / Δx

This is called the ab-initio method — deriving a derivative straight from its definition.

Finding a derivative for any function

There are two routes: apply the ab-initio limit definition directly, or memorise the derivatives of well-known functions and combine them using a handful of rules.

Worked example: f(x) = x²

f′(x) = lim Δx→0 [ (x+Δx)² − x² ] / Δx
= lim Δx→0 [ (Δx)² + 2x(Δx) ] / Δx
= lim Δx→0 ( Δx + 2x )
= 2x

Plotting f'(x) = 2x against the numerically-estimated slope of f(x) = x² at every point confirms the two match exactly.

Power rule. For any function of the form f(x) = xⁿ, bring the exponent down as a multiplier and reduce it by one: d/dx[xⁿ] = n·xn−1. So f(x) = x gives f'(x) = 1, and f(x) = −x gives f'(x) = −1.

The absolute-value function, f(x) = |x|

|x| splits into two pieces: f(x) = x for x > 0, and f(x) = −x for x < 0, with f(0) = 0. Each piece differentiates on its own (1 and −1 respectively) — the interesting question is what happens exactly at x = 0, covered next.

Checking if a function is differentiable

The test:
  1. Find the first derivative, f′(x).
  2. Check whether f′(x) itself is continuous.
  3. If f′(x) is discontinuous at a point, then f(x) is not differentiable there.

For f(x) = |x|: the derivative is +1 for x > 0 and −1 for x < 0, and undefined at x = 0 — a jump discontinuity in f′(x). Geometrically, infinitely many lines could touch the sharp "V" at the origin, so no single tangent — and hence no derivative — exists there.

By contrast, f(x) = x² has derivative f'(x) = 2x, a straight, continuous line through every x — so x² is differentiable everywhere.

Differentiability checker: |x| at x = 0

Move the point toward x = 0 from either side and watch the one-sided slope.

A kink (sharp corner) or a jump/break in the curve makes a function non-differentiable at that point, even if the function itself is still perfectly continuous there (as with |x|).

Rules of differentiation

Once the derivatives of basic functions are known, these four rules let you differentiate almost any combination of them.

Linearity rule +
For h(x) = g(x) + f(x), differentiate each term separately and add: h'(x) = g'(x) + f'(x).

Example: f(x) = x³ + log(x) → f'(x) = 3x² + 1/x.

For a constant multiple, h(x) = c·f(x), keep c untouched: h'(x) = c·f'(x).
Example: f(x) = 3·sin(x) → f'(x) = 3·cos(x).
Product rule +
For h(x) = g(x)·f(x): treat g(x) as constant while differentiating f(x), then treat f(x) as constant while differentiating g(x), and add the two.

h'(x) = f'(x)·g(x) + f(x)·g'(x)
Quotient rule +
For h(x) = f(x) / g(x):
  1. Differentiate the numerator, keep the denominator as-is.
  2. Keep the numerator as-is, differentiate the denominator.
  3. Subtract: step 1 result minus step 2 result.
  4. Divide the whole thing by [g(x)]².
Chain rule +
For a function nested inside another, h(x) = f(g(x)):
  1. Treat g(x) as a constant and differentiate the outer function f.
  2. Multiply that result by the derivative of the inner function, g'(x).

Using derivatives for optimisation

Along any curve, the sign of the slope (the derivative) tells you whether the function is rising or falling. Points where the slope changes sign — or equivalently, where the derivative equals exactly zero — are called critical points.

Minima

Slope goes negative → positive moving left to right. The curve dips and rises again.

Maxima

Slope goes positive → negative moving left to right. The curve rises and then falls.

Global vs. local

Among several minima, the lowest overall is the global minimum; the rest are local minima. Same logic for maxima.

The second-derivative test

Rather than manually comparing slopes just left and right of a point, take the second derivative at each critical point (where f′(x) = 0):

f″(x) > 0Minima — slope is increasing through the point (curving upward)
f″(x) < 0Maxima — slope is decreasing through the point (curving downward)
f″(x) = 0Saddle point — derivative is zero but the sign of the slope does not flip on either side
A saddle point has a flat tangent (f′ = 0) but is neither a minimum nor a maximum: the slope has the same sign immediately to its left and right.
